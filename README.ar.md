# ترجم (tarjim)

**ترجمة ودبلجة لأي فيديو، بلغتك، على جهازك.**
[English](README.md)

الصق رابط أو اسحب ملف. ترجم يسمع الكلام، ويضبط كل سطر على لحظة نطقه، ويفصل كلام كل شخص، ويترجم بلغة طبيعية، وبعدها يحرق الترجمة داخل الفيديو، أو يطلع ملف `srt`، أو يدبلجه بصوت لكل متكلم.

## وش يسوي

- **أي مصدر:** روابط يوتيوب وإكس وغيرها، أو أي فيديو أو صوت على جهازك.
- **34 لغة هدف** من اليمين لليسار ومن اليسار لليمين. العربي بلهجة سعودية افتراضياً، والفصحى بضغطة.
- **سماع دقيق:** يسمع الصوت ثلاث مرات ويصوّت على كل كلمة، فغلطة سماع وحدة ما توصل للترجمة.
- **توقيت مضبوط:** الكلمات تُضبط على الصوت داخل جهازك، والترجمة ما تعبر قصّة اللقطة لوجه الشخص الثاني.
- **يعرف المتكلمين:** الحوار بشرطة، سطر لكل متكلم.
- **دبلجة:** صوت طبيعي من Gemini لكل متكلم حسب طبقة صوته، أو استنساخ صوت كل متكلم على جهازك، أو أصوات استوديو، أو Fish Audio. ونص صوتي مستقل يكتب الأسماء بنطقها الصحيح والأرقام بالكلمات.
- **ثلاث طرق للاستخدام:** قائمة الزر الأيمن في المتصفح «ترجم للعربية»، أو صفحة ترجم، أو المحادثة: تضيف ترجم لتطبيق Claude أو Claude Code أو Codex وتقول له «ترجم هذا الرابط».

## اربط الذكاء الاصطناعي بثلاث طرق

| الطريقة | الخيارات | ملاحظة |
|---|---|---|
| مفتاح API | Gemini و OpenAI و Anthropic و OpenRouter و DeepSeek و Qwen و Mistral و Groq و xAI، أو أي عنوان متوافق مع OpenAI | Gemini و OpenAI يقدرون يسمعون الكلام بعد. |
| اشتراكك | Claude عبر Claude Code، و ChatGPT عبر Codex، و GitHub Copilot، و Google AI عبر Antigravity | ترجم يشغّل برنامج الشركة نفسه بتسجيل دخولك. الاستهلاك من اشتراكك وتنطبق شروط كل شركة. |
| على جهازك | Ollama و LM Studio و Jan و llama.cpp و vLLM و KoboldCpp | يكتشفها تلقائياً مع نماذجها، وما يطلع شي من جهازك. |

تختار أي نموذج يقدمه المزوّد. ولو المحرك المختار تعطّل أو خلصت حصته، يكمل ترجم بالمحرك المحلي إذا كان موجود.

## التثبيت عن طريق ذكاءك الاصطناعي (خطوة وحدة)

في Claude Code:

```bash
claude plugin marketplace add willynilly0085-creator/tarjim
claude plugin install tarjim@tarjim
```

بعدها قل لذكاءك الاصطناعي «جهّز ترجم». يركّب المحرك في الخلفية (نسخة كرت الشاشة لو عندك كرت NVIDIA)، ويشغّله بدون أي نافذة، ويفتح صفحة الإعداد. ومن بعدها يستخدم أدوات ترجم مباشرة: «ترجم هذا الرابط للفرنسي واحرق الترجمة»، «خلّ الترجمة باشتراكي في Claude»، «حوّل للنموذج المحلي». ترجم أداة يشغّلها ذكاؤك الاصطناعي، مو مساعد ثاني تكلّمه. يحتاج البرنامج [uv](https://docs.astral.sh/uv/).

تطبيقات MCP الثانية (Codex و Cursor وغيرها): بعد تركيب المحرك أضف الأمر `tarjim-mcp` كخادم MCP، مثلاً `codex mcp add tarjim -- tarjim-mcp`. Codex يطلب موافقتك على كل استخدام لأداة، ولو تبي أدوات ترجم تشتغل بدون سؤال أضف `default_tools_approval_mode = "approve"` تحت `[mcp_servers.tarjim]` في `~/.codex/config.toml`.

جُرّب: جلسة Claude Code مع الإضافة قرأت الإعدادات، وضبطت قاموس المصطلحات، وترجمت رابط يوتيوب للإسباني ورجّعت الترجمة. و Codex (باشتراك ChatGPT) قرأ الإعدادات وضبط القاموس. أما موقع ChatGPT وتطبيقه فما يقدرون حالياً يوصلون لأدوات على جهازك (يقبلون خوادم MCP على الإنترنت بس)، فاستخدم Codex مع ChatGPT.

## التثبيت يدوياً (ويندوز)

يحتاج Python 3.11 وحوالي 10 GB للنماذج المحلية.

```powershell
git clone https://github.com/willynilly0085-creator/tarjim
cd tarjim
python -m venv .venv
# لو عندك كرت NVIDIA: ثبّت نسخة PyTorch للكرت أول (النسخة الافتراضية للمعالج بس)
.venv\Scripts\python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python -m pip install -e ".[dub]"
.venv\Scripts\tarjim-serve
```

افتح <http://127.0.0.1:17653>. صفحة الإعداد تفحص جهازك، وتربط الذكاء الاصطناعي، وتنزّل اللي تحتاجه ومنها ffmpeg (على ويندوز ينزل ويُتحقق من بصمته المنشورة). وبدون كرت شاشة كل شي يشتغل على المعالج، بس أبطأ.

**ماك ولينكس:** نفس الخطوات بـ `.venv/bin/...` مع `brew install ffmpeg` أو `sudo apt install ffmpeg`. ما جُرّبت هذي الأنظمة بعد.

### إضافة المتصفح

ترجم يعيش في متصفحك: كليك يمين على أي فيديو أو رابط واختر **ترجم للعربية**، وبعدها ترجمة أو ترجمة داخل الفيديو أو دبلجة. والنافذة الصغيرة تعرض مرحلة كل مهمة وتخليك توقفها أو تلغيها أو تفتح النتيجة.

في كروم افتح `chrome://extensions`، فعّل وضع المطوّر، اختر **Load unpacked** وحدد مجلد `extension`. الإضافة تربط نفسها: اضغط **سماح** في صفحة ترجم.

### المحادثة

في صفحة الإعداد، خطوة «استخدم ترجم من المحادثة»، اضغط **أضف** جنب تطبيق Claude أو Claude Code أو Codex. بعدها ذكاؤك الاصطناعي يشغّل الأداة كاملة عنك:

- «ترجم هذا الرابط للعربي ودبلجه»، «وين وصلت؟»، «وقّفها مؤقت»، «افتح النتيجة».
- يغيّر الإعدادات: «خلّ الترجمة باشتراكي في Claude»، «حوّل للنموذج المحلي»، «وش الذكاءات اللي أقدر أربطها؟»، «خلّ الواجهة إنجليزي».
- يقرأ لك الترجمة الجاهزة، ويعيد المهمة لو فشلت، وينزّل الأداة الناقصة.

والمفاتيح ما تنكتب في المحادثة أبداً: يفتح لك صفحة ترجم تدخلها هناك.

## الخصوصية والأمان

- **المفاتيح** تنحفظ في خزنة نظام التشغيل المشفّرة، وملف الإعدادات ما فيه ولا مفتاح.
- **اللي يطلع من جهازك** حسب طريقة الربط: صوت المقطع يروح لمزوّد السماع اللي اخترته، والنص يروح لمزوّد الترجمة والصوت اللي اخترتهم. وفي الوضع المحلي ما يطلع شي: قسنا هذا بمراقبة كل اتصال خلال مهمة محلية كاملة مع الدبلجة، والنتيجة صفر اتصالات خارجية. والنماذج تنفتح بدون إنترنت، والإنترنت يُستخدم بس وقت تنزيل أداة.
- **الخادم المحلي** يستمع على 127.0.0.1 بس. كل طلب يحتاج رمز أو كوكي الصفحة، والعناوين الغريبة مرفوضة، والمواقع ما تقدر توصل له ولا تطلب ربط، وما يقدّم أي ملف خارج مجلداته.

للإبلاغ عن مشكلة أمنية: [SECURITY.md](SECURITY.md).
