**Субтитры и озвучка для любого видео, на вашем языке, на вашем собственном компьютере.**

Вставьте ссылку или перетащите файл. tarjim слушает, привязывает каждую реплику к моменту, когда она
звучит, различает говорящих, переводит на естественный разговорный язык и вшивает субтитры в видео,
сохраняет файл `.srt` или озвучивает видео, подбирая голос для каждого говорящего.

## Что умеет tarjim

- **Любой источник:** ссылки на YouTube, X и другие сайты (yt-dlp) или любой видео- или аудиофайл на
  вашем устройстве.
- **34 целевых языка**, с письмом как справа налево, так и слева направо. Для арабского по умолчанию
  используется саудовский диалект; современный литературный арабский включается одним щелчком.
- **Внимательное прослушивание:** звук прослушивается трижды, и по каждому слову проводится
  голосование, поэтому единичная ошибка распознавания не попадает в субтитры.
- **Точный тайминг:** слова выравниваются по звуку прямо на вашем компьютере (принудительное
  выравнивание CTC плюс определение речевой активности). Субтитры никогда не переходят через
  монтажную склейку на кадр со следующим человеком.
- **Учёт говорящих:** реплики диалога с тире, по одной строке на каждого говорящего.
- **Озвучка:** естественный голос Gemini для каждого говорящего (подобранный по высоте тона),
  локальный клон голоса каждого говорящего (XTTS-v2), студийные голоса или Fish Audio. Отдельный
  текст для озвучки записывает имена так, как они произносятся, а числа — словами, чтобы голос
  произносил их правильно.
- **Три способа работы:** контекстное меню браузера по правому щелчку («ترجم للعربية»), локальная
  веб-страница или чат: добавьте tarjim в приложение Claude, в Claude Code или в Codex и попросите
  перевести ссылку.

## Подключение ИИ: три способа

| Способ | Варианты | Примечания |
|---|---|---|
| API-ключ | Gemini, OpenAI, Anthropic, OpenRouter, DeepSeek, Qwen, Mistral, Groq, xAI или любой OpenAI-совместимый адрес | Gemini и OpenAI также умеют слушать (распознавание речи в текст). |
| Ваша подписка | Claude (через Claude Code), ChatGPT (через Codex), GitHub Copilot, Google AI (через Antigravity) | tarjim запускает собственную программу поставщика с вашим входом в аккаунт. Использование расходует лимиты вашего тарифа, и действуют условия каждого поставщика. |
| На вашем компьютере | Ollama, LM Studio, Jan, llama.cpp, vLLM, KoboldCpp | Обнаруживаются автоматически вместе с их моделями. Ничто не покидает ваше устройство. |

Выберите любую модель, которую предлагает поставщик. Если выбранный движок даёт сбой или исчерпывает
квоту, tarjim переключается на локальный движок, если он доступен.

## Установка с помощью вашего ИИ (один шаг)

В Claude Code:

```bash
claude plugin marketplace add willynilly0085-creator/tarjim
claude plugin install tarjim@tarjim
```

Затем скажите своему ИИ «настрой tarjim». Он установит движок в фоновом режиме (сборку для
видеокарты, если у вас карта NVIDIA), запустит его без каких-либо окон и откроет страницу настройки.
С этого момента ваш ИИ пользуется инструментами tarjim напрямую: «переведи эту ссылку на французский
и вшей субтитры», «используй мою подписку Claude для перевода», «переключись на локальную модель».
tarjim — это инструмент, которым управляет ваш ИИ, а не ещё один ассистент для разговоров. Для
плагина нужен [uv](https://docs.astral.sh/uv/).

Другие MCP-приложения (Codex, Cursor и другие): после установки движка добавьте команду
`tarjim-mcp` как MCP-сервер, например `codex mcp add tarjim -- tarjim-mcp`. Codex запрашивает
подтверждение каждого вызова инструмента; чтобы инструменты tarjim запускались без вопросов,
добавьте `default_tools_approval_mode = "approve"` в раздел `[mcp_servers.tarjim]` файла
`~/.codex/config.toml`.

Проверено: сеанс Claude Code с плагином прочитал настройки, задал глоссарий, перевёл ссылку YouTube
на испанский и вернул субтитры; Codex (тариф ChatGPT) прочитал настройки и задал глоссарий. Сайт
ChatGPT и настольное приложение пока не могут обращаться к инструментам на вашем компьютере (они
принимают только удалённые MCP-серверы), поэтому для ChatGPT используйте Codex.

## Установка вручную (Windows)

Нужны Python 3.11 и около 10 ГБ места на диске для локальных моделей.

```powershell
git clone https://github.com/willynilly0085-creator/tarjim
cd tarjim
python -m venv .venv
# NVIDIA graphics card: install the CUDA build of PyTorch first (the default one is CPU only)
.venv\Scripts\python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python -m pip install -e ".[dub]"
.venv\Scripts\tarjim-serve
```

Откройте <http://127.0.0.1:17653>. Страница настройки проверит ваше устройство, подключит ИИ и
скачает всё необходимое, включая ffmpeg (в Windows он скачивается и сверяется с опубликованной
контрольной суммой SHA-256). Без подходящей видеокарты всё по-прежнему работает на процессоре,
только медленнее.

**macOS и Linux**: те же шаги с `.venv/bin/...`, плюс `brew install ffmpeg` или
`sudo apt install ffmpeg`. На этих платформах программа ещё не тестировалась.

### Расширение для браузера

tarjim живёт в вашем браузере: щёлкните правой кнопкой мыши по любому видео или ссылке, выберите
**ترجم للعربية** (или ваш язык), а затем субтитры, вшитые субтитры или озвучку. Во всплывающем окне
видна стадия каждой задачи; там же её можно приостановить, отменить или открыть результат.

В Chrome откройте `chrome://extensions`, включите Developer mode (режим разработчика), нажмите
**Load unpacked** (загрузить распакованное расширение) и выберите папку `~/.tarjim/extension`. Расширение
подключается само: нажмите **Allow** (разрешить) на странице tarjim.

### Чат

На странице настройки, на шаге «Use tarjim from a chat» (использовать tarjim из чата), нажмите
**Add** (добавить) рядом с приложением Claude, Claude Code или Codex. После этого ваш ИИ сможет
управлять всем инструментом за вас:

- «Переведи эту ссылку на арабский и озвучь», «на какой она стадии?», «поставь на паузу», «открой
  результат»;
- менять настройки: «используй мою подписку Claude для перевода», «переключись на локальную модель»,
  «покажи, какие ИИ я могу подключить», «сделай интерфейс на английском»;
- зачитывать вам готовые субтитры, повторять неудавшуюся задачу или скачивать недостающий
  инструмент.

Ключи никогда не вводятся через чат; для этого ИИ открывает страницу tarjim.

### Командная строка

```bash
tarjim video.mp4                 # Arabic (Saudi), burned into the video
tarjim video.mp4 --to fr         # any target language
tarjim video.mp4 --no-burn       # .srt and .ass only
```

## Конфиденциальность и безопасность

- **Ключи** хранятся в зашифрованном хранилище вашей операционной системы (Windows Credential
  Manager, macOS Keychain, Secret Service). В файле настроек их нет.
- **Что покидает ваше устройство**, зависит от способа подключения: звук ролика отправляется
  выбранному вами поставщику распознавания речи, а текст — выбранным вами поставщикам перевода и
  озвучки. В локальном режиме наружу не уходит ничего: это измерено наблюдением за каждым
  соединением во время полной локальной задачи, включая озвучку (ноль внешних соединений). Модели
  загружаются офлайн; интернет используется только при скачивании инструмента.
- **Локальный сервер** слушает только 127.0.0.1. Каждый запрос требует токен или same-site cookie
  страницы, чужие заголовки `Host` отклоняются (защита от DNS rebinding), веб-сайты не могут
  обратиться к нему или запросить сопряжение, и он не отдаёт никаких файлов за пределами своих
  папок.

Чтобы сообщить о проблеме, см. [SECURITY.md](SECURITY.md).

## Лицензии моделей

Код tarjim не содержит весов моделей; вы скачиваете их у владельцев. Некоторые из них **не
лицензированы для коммерческого использования**:

| Инструмент | Лицензия | Коммерческое использование |
|---|---|---|
| Выравниватель тайминга `MahmoudAshraf/mms-300m-1130-forced-aligner` (обязателен) | CC-BY-NC-4.0 | Нет |
| Клон голоса XTTS-v2 (необязателен, запрашивает согласие) | Coqui Public Model License | Нет |
| Локальный перевод `aya-expanse:8b` (необязателен) | CC-BY-NC-4.0 | Нет |
| Локальное распознавание речи Qwen3-ASR-1.7B и Qwen3-ForcedAligner | Apache-2.0 | Да |
| ffmpeg (сборка под LGPL) | LGPL-2.1 | Да |

Страница настройки показывает каждую лицензию рядом с соответствующей загрузкой.

## Состояние

Проверено в Windows 11 с RTX 5080, а также на чистой установке без поддержки видеокарты: ссылки и
файлы, вшитые субтитры и `.srt`, французский и арабский, пауза, возобновление, отмена и повтор, три
способа подключения (подписки Claude и ChatGPT, локальный Ollama), инструменты чата и описанные выше
проверки безопасности. Ещё не проверено: macOS, Linux, подписки GitHub Copilot и Antigravity.
