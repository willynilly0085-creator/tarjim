**کسی بھی ویڈیو کے لیے سب ٹائٹل اور ڈبنگ، آپ کی زبان میں، آپ کے اپنے کمپیوٹر پر۔**

لنک چسپاں کیجیے یا فائل ڈال دیجیے۔ tarjim سنتا ہے، ہر سطر کو ٹھیک اُس لمحے سے ملاتا ہے جب وہ بولی
جاتی ہے، ہر بولنے والے کو الگ رکھتا ہے، فطری بول چال کی زبان میں ترجمہ کرتا ہے، اور پھر سب ٹائٹل کو
ویڈیو میں ثبت کر دیتا ہے، `.srt` فائل بناتا ہے، یا ہر بولنے والے کے لیے ایک آواز کے ساتھ اس کی ڈبنگ کرتا ہے۔

## یہ کیا کرتا ہے

- **کوئی بھی ماخذ:** YouTube، X اور دوسرے لنک (yt-dlp)، یا آپ کے آلے پر موجود کوئی بھی ویڈیو یا آڈیو فائل۔
- **34 ہدف زبانیں**، دائیں سے بائیں اور بائیں سے دائیں دونوں۔ عربی میں طے شدہ طور پر سعودی لہجہ ہوتا ہے؛
  جدید معیاری عربی بس ایک کلک کی دوری پر ہے۔
- **غور سے سننا:** آڈیو تین بار سنا جاتا ہے اور ہر لفظ پر ووٹنگ ہوتی ہے، تاکہ ایک بار کا غلط سنا ہوا
  لفظ سب ٹائٹل تک نہ پہنچے۔
- **درست ٹائمنگ:** الفاظ کو آپ کے کمپیوٹر پر ہی آڈیو سے ملایا جاتا ہے (CTC forced alignment کے ساتھ
  voice-activity detection)۔ سب ٹائٹل کبھی شاٹ کٹ کے پار اگلے شخص کے شاٹ میں نہیں جاتے۔
- **بولنے والے کی پہچان:** مکالمے کی سطریں ڈیش کے ساتھ، ہر بولنے والے کی ایک سطر۔
- **ڈبنگ:** ہر بولنے والے کے لیے ایک فطری Gemini آواز (سُر کے لحاظ سے ملائی گئی)، ہر بولنے والے کی مقامی
  وائس کلون (VoxCPM2)، اسٹوڈیو آوازیں، یا Fish Audio۔ ایک الگ آواز کا اسکرپٹ ناموں کو ویسے لکھتا ہے جیسے
  وہ بولے جاتے ہیں اور اعداد کو الفاظ میں، تاکہ آواز انہیں درست ادا کرے۔
- **استعمال کے تین طریقے:** براؤزر میں رائٹ کلک مینو ("ترجم للعربية")، ایک مقامی ویب صفحہ،
  یا چیٹ: tarjim کو Claude ایپ، Claude Code یا Codex میں شامل کیجیے اور اس سے کسی لنک کا ترجمہ کرنے کو کہیے۔

## AI جوڑنے کے تین طریقے

| طریقہ | انتخاب | نوٹ |
|---|---|---|
| API کلید | Gemini، OpenAI، Anthropic، OpenRouter، DeepSeek، Qwen، Mistral، Groq، xAI، یا کوئی بھی OpenAI سے مطابقت رکھنے والا پتہ | Gemini اور OpenAI سن بھی سکتے ہیں (بولی سے متن)۔ |
| آپ کی رکنیت | Claude (Claude Code کے ذریعے)، ChatGPT (Codex کے ذریعے)، GitHub Copilot، Google AI (Antigravity کے ذریعے) | tarjim آپ کے سائن اِن کے ساتھ فراہم کنندہ کا اپنا پروگرام چلاتا ہے۔ استعمال آپ کے پلان میں شمار ہوتا ہے اور ہر فراہم کنندہ کی شرائط لاگو ہوتی ہیں۔ |
| آپ کے کمپیوٹر پر | Ollama، LM Studio، Jan، llama.cpp، vLLM، KoboldCpp | اپنے ماڈلز سمیت خود بخود مل جاتے ہیں۔ کچھ بھی آپ کے آلے سے باہر نہیں جاتا۔ |

کسی فراہم کنندہ کا کوئی بھی ماڈل منتخب کیجیے۔ اگر منتخب انجن ناکام ہو جائے یا اس کا کوٹہ ختم ہو جائے، تو
مقامی انجن دستیاب ہونے پر tarjim اس پر واپس آ جاتا ہے۔

## آپ کے کمپیوٹر کو کیا چاہیے

بھاری حصے اختیاری ہیں۔ آپ کو کیا چاہیے، یہ اس پر منحصر ہے کہ کون سے حصے آپ کے اپنے کمپیوٹر پر چلتے
ہیں:

| آپ کیا استعمال کرتے ہیں | گرافکس کارڈ | میموری (RAM) | خالی ڈسک |
|---|---|---|---|
| آپ کے جوڑے ہوئے AI کے ساتھ سب ٹائٹل (Gemini کلید، Claude یا ChatGPT کی رکنیت، کوئی بھی API کلید) | ضرورت نہیں | 8 GB | تقریباً 6 GB |
| فطری یا اسٹوڈیو آوازوں کے ساتھ ڈبنگ | ضرورت نہیں | 8 GB | کچھ اضافی نہیں |
| اس کمپیوٹر پر سننا (آڈیو کبھی باہر نہیں جاتا) | NVIDIA، 8 GB | 16 GB | مزید 6.3 GB |
| اس کمپیوٹر پر ترجمہ (Ollama کے ساتھ aya-expanse 8B) | 8 GB | 16 GB | مزید 5.1 GB |
| ہر بولنے والے کی اپنی آواز میں ڈبنگ | NVIDIA، 8 GB | 16 GB | مزید 4.7 GB |

- **سسٹم:** Windows 10 یا 11، 64 بٹ۔ macOS اور Linux وہی کوڈ چلاتے ہیں مگر ابھی ان کی جانچ نہیں
  ہوئی۔
- **انٹرنیٹ:** ڈاؤن لوڈز کے لیے اور آپ کے جوڑے ہوئے AI کے لیے۔ سننا اور ترجمہ اس کمپیوٹر پر ہوں تو
  سب کچھ ڈاؤن لوڈ ہو جانے کے بعد کام آف لائن چلتے ہیں۔
- **NVIDIA کارڈ کے بغیر** بھی سب کچھ پروسیسر پر چلتا ہے، بس بہت سست؛ بولنے والے کی اپنی آواز میں
  ڈبنگ وہاں عملی نہیں۔
- **ایک وقت میں ایک ماڈل:** tarjim اگلا ماڈل لوڈ ہونے سے پہلے ہر ماڈل کو آزاد کر دیتا ہے، اس لیے
  گرافکس کارڈ میں سب سے بڑے ماڈل (تقریباً 6 GB) کی جگہ چاہیے، سب کے لیے اکٹھی نہیں۔
- **سب کچھ اس کمپیوٹر پر:** تقریباً 22 GB ڈسک۔

Windows 11 پر RTX 5080 (16 GB) اور 32 GB RAM کے ساتھ ناپا گیا: کارڈ پر سننے میں گرافکس میموری زیادہ
سے زیادہ 5.9 GB رہی، aya-expanse 8B سے ترجمے میں 5.7 GB اور بولنے والے کی اپنی آواز میں 6.1 GB،
تقریباً 3 سیکنڈ فی جملہ۔ بولنے والے کی آواز کا ماڈل لوڈ ہوتے وقت کچھ دیر کے لیے تقریباً 11 GB RAM
لیتا ہے اور پھر 2.5 GB پر ٹھہر جاتا ہے، اسی لیے یہ 16 GB مانگتا ہے۔ انجن خود (Python اور PyTorch کا
گرافکس کارڈ والا ورژن) اوپر دیے گئے ڈسک کے اعداد میں سے تقریباً 4 GB لیتا ہے۔

## اپنے AI کے ساتھ انسٹال کریں (ایک قدم)

Claude Code میں:

```bash
claude plugin marketplace add willynilly0085-creator/tarjim
claude plugin install tarjim@tarjim
```

پھر اپنے AI سے کہیے "set up tarjim"۔ وہ پس منظر میں انجن انسٹال کرتا ہے (اگر آپ کے پاس NVIDIA کارڈ ہو
تو گرافکس کارڈ والا بلڈ)، اسے کسی ونڈو کے بغیر چلاتا ہے اور سیٹ اپ صفحہ کھول دیتا ہے۔ اس کے بعد سے آپ کا
AI براہِ راست tarjim کے ٹولز استعمال کرتا ہے: "اس لنک کا فرانسیسی میں ترجمہ کرو اور سب ٹائٹل ثبت کر دو"،
"ترجمے کے لیے میری Claude رکنیت استعمال کرو"، "مقامی ماڈل پر چلے جاؤ"۔ tarjim ایک ٹول ہے جسے آپ کا AI
چلاتا ہے، بات کرنے کے لیے کوئی اور معاون نہیں۔ پلگ اِن کو [uv](https://docs.astral.sh/uv/) درکار ہے۔

دوسری MCP ایپس (Codex، Cursor، اور مزید): انجن انسٹال ہونے کے بعد `tarjim-mcp` کمانڈ کو MCP سرور کے طور پر
شامل کیجیے، مثال کے طور پر `codex mcp add tarjim -- tarjim-mcp`۔ Codex ہر ٹول کال پر آپ سے منظوری مانگتا
ہے؛ tarjim کے ٹولز کو پوچھے بغیر چلنے دینے کے لیے `~/.codex/config.toml` میں `[mcp_servers.tarjim]` کے نیچے
`default_tools_approval_mode = "approve"` شامل کیجیے۔

آزمایا گیا: پلگ اِن والے ایک Claude Code سیشن نے ترتیبات پڑھیں، اصطلاحات کی فہرست طے کی، ایک YouTube لنک
کا ہسپانوی میں ترجمہ کیا اور سب ٹائٹل واپس کیے؛ Codex (ChatGPT پلان) نے ترتیبات پڑھیں اور اصطلاحات کی
فہرست طے کی۔ ChatGPT ویب سائٹ اور ڈیسک ٹاپ ایپ ابھی آپ کے کمپیوٹر کے ٹولز تک نہیں پہنچ سکتیں (وہ صرف
ریموٹ MCP سرور قبول کرتی ہیں)، اس لیے ChatGPT کے لیے Codex استعمال کیجیے۔

## ہاتھ سے انسٹال کریں (Windows)

Python 3.11 چاہیے۔ ڈسک، میموری اور گرافکس کارڈ: دیکھیں [آپ کے کمپیوٹر کو کیا چاہیے](#آپ-کے-کمپیوٹر-کو-کیا-چاہیے)۔

```powershell
git clone https://github.com/willynilly0085-creator/tarjim
cd tarjim
python -m venv .venv
# NVIDIA graphics card: install the CUDA build of PyTorch first (the default one is CPU only)
.venv\Scripts\python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python -m pip install -e ".[dub]"
.venv\Scripts\tarjim-serve
```

<http://127.0.0.1:17653> کھولیے۔ سیٹ اپ صفحہ آپ کے آلے کی جانچ کرتا ہے، ایک AI جوڑتا ہے، اور ضرورت کی
چیزیں ڈاؤن لوڈ کرتا ہے، جن میں ffmpeg بھی شامل ہے (Windows پر اسے ڈاؤن لوڈ کر کے اس کے شائع شدہ SHA-256 سے
جانچا جاتا ہے)۔ قابلِ استعمال گرافکس کارڈ نہ ہو تب بھی سب کچھ پروسیسر پر چلتا ہے، بس آہستہ۔

**macOS اور Linux** پر یہی اقدامات `.venv/bin/...` کے ساتھ کیجیے، ساتھ میں `brew install ffmpeg` یا
`sudo apt install ffmpeg`۔ ان پلیٹ فارمز کو ابھی آزمایا نہیں گیا۔

### براؤزر ایکسٹینشن

tarjim آپ کے براؤزر میں رہتا ہے: کسی بھی ویڈیو یا لنک پر رائٹ کلک کر کے **ترجم للعربية** (یا اپنی زبان)
منتخب کیجیے، پھر سب ٹائٹل، ویڈیو میں ثبت سب ٹائٹل یا ڈبنگ چنیے۔ پاپ اپ ہر کام کا مرحلہ دکھاتا ہے اور آپ کو
اسے روکنے، منسوخ کرنے یا نتیجہ کھولنے دیتا ہے۔

Chrome میں `chrome://extensions` کھولیے، Developer mode (ڈیولپر موڈ) آن کیجیے، **Load unpacked**
(غیر پیک شدہ لوڈ کریں) منتخب کیجیے اور `~/.tarjim/extension` فولڈر چنیے۔ ایکسٹینشن خود کو جوڑ لیتی ہے: tarjim صفحے پر
**Allow** (اجازت دیں) دبائیے۔

### چیٹ

سیٹ اپ صفحے پر، "Use tarjim from a chat" مرحلے میں، Claude ایپ، Claude Code یا Codex کے سامنے **Add**
(شامل کریں) دبائیے۔ پھر آپ کا AI آپ کے لیے پورا ٹول چلا سکتا ہے:

- "اس لنک کا عربی میں ترجمہ کرو اور ڈبنگ کرو"، "یہ کس مرحلے پر ہے؟"، "اسے روکو"، "نتیجہ کھولو"؛
- ترتیبات بدلنا: "ترجمے کے لیے میری Claude رکنیت استعمال کرو"، "مقامی ماڈل پر چلے جاؤ"،
  "وہ AI دکھاؤ جنہیں میں جوڑ سکتا ہوں"، "انٹرفیس انگریزی میں کر دو"؛
- تیار سب ٹائٹل آپ کو پڑھ کر سنانا، ناکام کام دوبارہ چلانا، یا کوئی غائب ٹول ڈاؤن لوڈ کرنا۔

کلیدیں کبھی چیٹ کے ذریعے درج نہیں کی جاتیں؛ اس کے لیے AI tarjim کا صفحہ کھول دیتا ہے۔

### فون

کسی بھی فون سے، iPhone یا Android، گھر پر ہوں یا باہر، اپنے ہی Telegram بوٹ کو ویڈیو کا لنک بھیجیے، اور
ترجمہ شدہ ویڈیو اسی چیٹ میں واپس آ جاتی ہے۔ ترتیبات میں **فون** کھولیے: BotFather میں ایک بوٹ بنائیے
(`/newbot`)، اس کا ٹوکن چسپاں کیجیے (وہ آپ کے کمپیوٹر کی تجوری میں ہی رہتا ہے)، پھر اپنے فون سے QR کوڈ
اسکین کیجیے اور **Start** دبائیے۔ بوٹ صرف آپ کے اکاؤنٹ کو جواب دیتا ہے، اور آپ کا کمپیوٹر خود Telegram سے
نئے پیغامات مانگتا ہے، اس لیے انٹرنیٹ کے لیے کوئی پورٹ نہیں کھولا جاتا۔ زبان، نتیجہ اور انداز ترتیبات سے
آتے ہیں؛ بوٹ میں `/mode` نتیجہ بدلتا ہے۔ Telegram بوٹس کو 20 MB تک کی ویڈیوز ڈاؤن لوڈ کرنے اور 50 MB تک کی
فائلیں بھیجنے دیتا ہے: اس سے بڑا نتیجہ چھوٹا کر کے دوبارہ انکوڈ کیا جاتا ہے، یا آپ کو سب ٹائٹل فائل ملتی ہے
اور مکمل ویڈیو آپ کے کمپیوٹر پر ہی رہتی ہے۔ بوٹ اس وقت تک جواب دیتا ہے جب تک آپ کا کمپیوٹر اور tarjim چل
رہے ہوں۔

### کمانڈ لائن

```bash
tarjim video.mp4                 # Arabic (Saudi), burned into the video
tarjim video.mp4 --to fr         # any target language
tarjim video.mp4 --no-burn       # .srt and .ass only
```

## اپ ڈیٹس

tarjim خود کو اپ ڈیٹ رکھتا ہے۔ دن میں ایک بار انجن GitHub سے تازہ ترین ریلیز کا نمبر پوچھتا ہے: ایک
ہی درخواست، جس میں آپ یا آپ کی ویڈیوز کے بارے میں کچھ نہیں ہوتا۔ **نیا ورژن آنے پر tarjim کو خود
بخود اپ ڈیٹ کریں** آن ہو (سیٹ اپ کے دوران پیش کیا جاتا ہے اور ترتیبات میں بدلا جا سکتا ہے) تو نئی
ریلیز پس منظر میں اس وقت انسٹال ہو جاتی ہے جب کوئی کام نہ چل رہا ہو، اور tarjim چند منٹ میں خود واپس
آ جاتا ہے؛ براؤزر ایکسٹینشن بھی اس کے مطابق خود ری لوڈ ہو جاتی ہے۔ آف ہو تو صفحہ ایک نوٹس اور **ابھی
اپ ڈیٹ کریں** بٹن دکھاتا ہے۔ سورس سے چلائی گئی کاپی `git pull` سے اپ ڈیٹ ہوتی ہے۔
