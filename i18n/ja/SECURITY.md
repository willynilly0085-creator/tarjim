## 問題の報告

セキュリティ上の問題は、公開の issue ではなく、このリポジトリにある GitHub の "Report a vulnerability"（脆弱性を報告）ボタンから非公開で報告してください。見つけた内容、再現手順、そしてそれによって何ができてしまうかを記載してください。報告はできるだけ早く確認し、返信します。

## tarjim が保護するもの

- **キーとペアリングトークン** は `keyring` を通じて OS の暗号化された保管庫に保存されます。設定ファイル、サーバーの応答、ログ、チャットツールに現れることは決してありません。
- **ローカルサーバー**（`tarjim-serve`）は 127.0.0.1 でのみ待ち受け、次のものを拒否します:
  - トークン（`X-Tarjim-Token`）もページの HttpOnly、SameSite=Strict の Cookie も持たないリクエスト;
  - `Host` がローカルでないリクエスト（DNS リバインディング）;
  - ブラウザー拡張機能以外から来たペアリング要求;
  - 自身の Web フォルダーとジョブの完成した出力以外のあらゆるパス。
- **サブスクリプション** は、各ベンダー純正のプログラム（Claude Code、Codex、Copilot、Antigravity）を実行することで利用します。tarjim がそれらのサインインファイルやトークンを読み取ったり保存したりすることは決してありません。
- **ローカルモード** ではメディアはデバイス内にとどまります。モデルは Hugging Face hub をオフラインにした状態で読み込まれ、ネットワークは本人が要求したツールのダウンロード中にしか使われません。
- **ダウンロード**: ffmpeg はリリースとともに公開されている SHA-256 と照合されます。

## 既知の制限

- あなたのコンピューター上であなたのユーザーとしてプログラムを実行できる人は、保管庫とトークンを読み取れます。tarjim は乗っ取られたアカウントに対しては防御しません。
- あなたが選んだクラウドプロバイダーは、処理する音声やテキストを各社の規約のもとで受け取ります。

## ライブラリの既知の問題

tarjim がインストールするライブラリで公表され、テスト済みのどのバージョンでもまだ避けられない脆弱性：現在はありません。見つかった場合、その内容は tarjim とともに `tarjim/known_issues.json` で配布されます。**設定**、エンジンの `/update` の応答、チャットツールの `setup_status` が、インストール済みのバージョンが該当するコンピューターに表示し、アップデートで修正版が入ると自動的に消えます。ここにない脆弱性があると CI は失敗し、毎週のチェックが一覧のものを修正できるようになったときに知らせます。

**2026-10-23 に解消。** 当時のローカル聞き取りエンジン qwen-asr が transformers を 4.57.6 に固定していた間、transformers の6件の勧告（PYSEC-2025-217, PYSEC-2026-2288, PYSEC-2026-2289, PYSEC-2026-2290, PYSEC-2026-3929, PYSEC-2026-4174）が残っていました。ローカルの聞き取りは Transformers 自身の Qwen3-ASR モデルで動くようになったため、tarjim は transformers 5.20.2 をインストールし、qwen-asr はインストールしなくなりました。accelerate は上書きなしで 1.15.0 のままです（PYSEC-2026-3804 は解消）。

**tarjim が常に行っていること。** Hugging Face のモデルはどれも固定のコミット（`tarjim/model_pins.py`）からダウンロードし、取得するのは設定、トークナイザー、チャットテンプレート、safetensors ファイルだけで、コードは取得しません。大きなファイルは公開されている SHA-256 と一致する必要があり、ハブをオフラインにしたまま、コンピューター上のそのフォルダーから読み込みます。`trust_remote_code` は一切使わず、`kernels` パッケージもインストールしていません。音声分離の重みは demucs 自身のモデルクラスを指す場合だけ、発音記号モデルは両方のファイルがリリースの SHA-256 と一致する場合だけ読み込みます。
