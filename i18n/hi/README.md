# tarjim

**किसी भी वीडियो के लिए सबटाइटल और डबिंग, आपकी भाषा में, आपके अपने कंप्यूटर पर।**

लिंक चिपकाइए या फ़ाइल डालिए। tarjim सुनता है, हर पंक्ति को ठीक उसी पल से मिलाता है जब वह बोली
जाती है, हर वक्ता को अलग रखता है, स्वाभाविक बोलचाल की भाषा में अनुवाद करता है, और फिर सबटाइटल को
वीडियो में जला देता है, `.srt` फ़ाइल बनाता है, या हर वक्ता के लिए एक आवाज़ के साथ उसकी डबिंग करता है।

## यह क्या करता है

- **कोई भी स्रोत:** YouTube, X और दूसरे लिंक (yt-dlp), या आपके डिवाइस पर मौजूद कोई भी वीडियो या ऑडियो फ़ाइल।
- **34 लक्ष्य भाषाएँ**, दाएँ-से-बाएँ और बाएँ-से-दाएँ दोनों। अरबी में डिफ़ॉल्ट रूप से सऊदी बोली होती है;
  मानक आधुनिक अरबी बस एक क्लिक दूर है।
- **ध्यान से सुनना:** ऑडियो तीन बार सुना जाता है और हर शब्द पर मतदान होता है, ताकि एक बार की ग़लत
  सुनवाई सबटाइटल तक न पहुँचे।
- **सटीक टाइमिंग:** शब्दों को आपके कंप्यूटर पर ही ऑडियो से मिलाया जाता है (CTC forced alignment के साथ
  voice-activity detection)। सबटाइटल कभी भी शॉट कट के पार अगले व्यक्ति के शॉट में नहीं खिंचते।
- **वक्ता की पहचान:** संवाद की पंक्तियाँ डैश के साथ, हर वक्ता की एक पंक्ति।
- **डबिंग:** हर वक्ता के लिए एक स्वाभाविक Gemini आवाज़ (सुर के हिसाब से मिलाई गई), हर वक्ता की लोकल
  वॉइस क्लोन (XTTS-v2), स्टूडियो आवाज़ें, या Fish Audio। एक अलग आवाज़-स्क्रिप्ट नामों को वैसे लिखती है
  जैसे वे बोले जाते हैं और संख्याओं को शब्दों में, ताकि आवाज़ उन्हें सही बोले।
- **इस्तेमाल के तीन तरीक़े:** ब्राउज़र में राइट-क्लिक मेनू ("ترجم للعربية"), एक लोकल वेब पेज,
  या चैट: tarjim को Claude ऐप, Claude Code या Codex में जोड़िए और उससे किसी लिंक का अनुवाद करने को कहिए।

## AI जोड़ने के तीन तरीक़े

| तरीक़ा | विकल्प | टिप्पणी |
|---|---|---|
| API कुंजी | Gemini, OpenAI, Anthropic, OpenRouter, DeepSeek, Qwen, Mistral, Groq, xAI, या कोई भी OpenAI-संगत पता | Gemini और OpenAI सुन भी सकते हैं (बोली से टेक्स्ट)। |
| आपकी सदस्यता | Claude (Claude Code के ज़रिए), ChatGPT (Codex के ज़रिए), GitHub Copilot, Google AI (Antigravity के ज़रिए) | tarjim आपके साइन-इन के साथ विक्रेता का अपना प्रोग्राम चलाता है। इस्तेमाल आपके प्लान में गिना जाता है और हर विक्रेता की शर्तें लागू होती हैं। |
| आपके कंप्यूटर पर | Ollama, LM Studio, Jan, llama.cpp, vLLM, KoboldCpp | अपने मॉडलों के साथ अपने-आप मिल जाते हैं। कुछ भी आपके डिवाइस से बाहर नहीं जाता। |

किसी प्रदाता का कोई भी मॉडल चुनिए। अगर चुना गया इंजन विफल हो जाए या उसका कोटा ख़त्म हो जाए, तो
लोकल इंजन उपलब्ध होने पर tarjim उस पर लौट आता है।

## अपने AI के साथ इंस्टॉल करें (एक क़दम)

Claude Code में:

```bash
claude plugin marketplace add willynilly0085-creator/tarjim
claude plugin install tarjim@tarjim
```

फिर अपने AI से कहिए "set up tarjim"। वह पृष्ठभूमि में इंजन इंस्टॉल करता है (आपके पास NVIDIA कार्ड हो
तो ग्राफ़िक्स-कार्ड वाला बिल्ड), उसे बिना किसी विंडो के चालू करता है और सेटअप पेज खोल देता है। उसके
बाद से आपका AI सीधे tarjim के टूल इस्तेमाल करता है: "इस लिंक का फ़्रेंच में अनुवाद करो और सबटाइटल
जला दो", "अनुवाद के लिए मेरी Claude सदस्यता इस्तेमाल करो", "लोकल मॉडल पर चले जाओ"। tarjim एक टूल है
जिसे आपका AI चलाता है, बात करने के लिए कोई और सहायक नहीं। प्लगइन को
[uv](https://docs.astral.sh/uv/) चाहिए।

दूसरे MCP ऐप (Codex, Cursor, और भी): इंजन इंस्टॉल होने के बाद `tarjim-mcp` कमांड को MCP सर्वर के रूप में
जोड़िए, उदाहरण के लिए `codex mcp add tarjim -- tarjim-mcp`। Codex हर टूल कॉल पर आपसे मंज़ूरी माँगता है;
tarjim के टूल बिना पूछे चलने देने के लिए `~/.codex/config.toml` में `[mcp_servers.tarjim]` के नीचे
`default_tools_approval_mode = "approve"` जोड़िए।

परखा गया: प्लगइन वाले एक Claude Code सत्र ने सेटिंग पढ़ीं, शब्दावली तय की, एक YouTube लिंक का स्पेनिश
में अनुवाद किया और सबटाइटल लौटाए; Codex (ChatGPT प्लान) ने सेटिंग पढ़ीं और शब्दावली तय की। ChatGPT
वेबसाइट और डेस्कटॉप ऐप अभी आपके कंप्यूटर के टूल तक नहीं पहुँच सकते (वे केवल रिमोट MCP सर्वर स्वीकार
करते हैं), इसलिए ChatGPT के लिए Codex इस्तेमाल करें।

## हाथ से इंस्टॉल करें (Windows)

Python 3.11 और लोकल मॉडलों के लिए लगभग 10 GB डिस्क चाहिए।

```powershell
git clone https://github.com/willynilly0085-creator/tarjim
cd tarjim
python -m venv .venv
# NVIDIA graphics card: install the CUDA build of PyTorch first (the default one is CPU only)
.venv\Scripts\python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python -m pip install -e ".[dub]"
.venv\Scripts\tarjim-serve
```

<http://127.0.0.1:17653> खोलिए। सेटअप पेज आपके डिवाइस की जाँच करता है, एक AI जोड़ता है, और ज़रूरी
चीज़ें डाउनलोड करता है, जिनमें ffmpeg भी शामिल है (Windows पर इसे डाउनलोड करके उसके प्रकाशित SHA-256 से
जाँचा जाता है)। इस्तेमाल लायक़ ग्राफ़िक्स कार्ड न हो तब भी सब कुछ प्रोसेसर पर चलता है, बस धीमा।

**macOS और Linux** पर यही क़दम `.venv/bin/...` के साथ अपनाइए, साथ में `brew install ffmpeg` या
`sudo apt install ffmpeg`। इन प्लेटफ़ॉर्म को अभी परखा नहीं गया है।

### ब्राउज़र एक्सटेंशन

tarjim आपके ब्राउज़र में रहता है: किसी भी वीडियो या लिंक पर राइट-क्लिक करके **ترجم للعربية** (या अपनी
भाषा) चुनिए, फिर सबटाइटल, वीडियो में जले सबटाइटल या डबिंग चुनिए। पॉपअप हर काम का चरण दिखाता है और
आपको उसे रोकने, रद्द करने या नतीजा खोलने देता है।

Chrome में `chrome://extensions` खोलिए, Developer mode (डेवलपर मोड) चालू कीजिए, **Load unpacked**
(अनपैक्ड लोड करें) चुनिए और `~/.tarjim/extension` फ़ोल्डर चुनिए। एक्सटेंशन अपने-आप जुड़ जाता है: tarjim पेज पर
**Allow** (अनुमति दें) दबाइए।

### चैट

सेटअप पेज पर, "Use tarjim from a chat" चरण में, Claude ऐप, Claude Code या Codex के आगे **Add** (जोड़ें)
दबाइए। फिर आपका AI आपके लिए पूरा टूल चला सकता है:

- "इस लिंक का अरबी में अनुवाद करो और डबिंग करो", "यह किस चरण पर है?", "इसे रोको", "नतीजा खोलो";
- सेटिंग बदलना: "अनुवाद के लिए मेरी Claude सदस्यता इस्तेमाल करो", "लोकल मॉडल पर चले जाओ",
  "वे AI दिखाओ जिन्हें मैं जोड़ सकता हूँ", "इंटरफ़ेस अंग्रेज़ी में कर दो";
- तैयार सबटाइटल आपको पढ़कर सुनाना, विफल काम दोबारा चलाना, या कोई ग़ायब टूल डाउनलोड करना।

कुंजियाँ कभी भी चैट के ज़रिए नहीं डाली जातीं; उसके लिए AI tarjim पेज खोल देता है।

### कमांड लाइन

```bash
tarjim video.mp4                 # Arabic (Saudi), burned into the video
tarjim video.mp4 --to fr         # any target language
tarjim video.mp4 --no-burn       # .srt and .ass only
```

## निजता और सुरक्षा

- **कुंजियाँ** आपके ऑपरेटिंग सिस्टम की एन्क्रिप्टेड तिजोरी में रखी जाती हैं (Windows Credential Manager,
  macOS Keychain, Secret Service)। सेटिंग फ़ाइल में इनमें से कोई नहीं होती।
- **आपके डिवाइस से क्या बाहर जाता है**, यह जोड़ने के तरीक़े पर निर्भर है: क्लिप का ऑडियो आपके चुने हुए
  सुनने वाले प्रदाता के पास जाता है, और टेक्स्ट आपके चुने हुए अनुवाद और आवाज़ प्रदाताओं के पास।
  लोकल मोड में कुछ भी बाहर नहीं जाता: इसे डबिंग समेत एक पूरे लोकल काम के दौरान हर कनेक्शन पर नज़र
  रखकर मापा गया (शून्य बाहरी कनेक्शन)। मॉडल ऑफ़लाइन लोड होते हैं; इंटरनेट केवल तब इस्तेमाल होता है
  जब आप कोई टूल डाउनलोड करते हैं।
- **लोकल सर्वर** केवल 127.0.0.1 पर सुनता है। हर अनुरोध के लिए टोकन या पेज की same-site कुकी ज़रूरी है,
  बाहरी `Host` हेडर अस्वीकार किए जाते हैं (DNS rebinding), वेबसाइटें उस तक नहीं पहुँच सकतीं और न जुड़ने
  का अनुरोध कर सकती हैं, और वह अपने फ़ोल्डरों के बाहर की कोई फ़ाइल नहीं देता।

कोई समस्या रिपोर्ट करने के लिए [SECURITY.md](SECURITY.md) देखें।

## मॉडल लाइसेंस

tarjim के कोड में मॉडल वेट शामिल नहीं हैं; आप उन्हें उनके मालिकों से डाउनलोड करते हैं। इनमें से कुछ
**व्यावसायिक उपयोग के लिए लाइसेंस प्राप्त नहीं हैं**:

| टूल | लाइसेंस | व्यावसायिक उपयोग |
|---|---|---|
| टाइमिंग एलाइनर `MahmoudAshraf/mms-300m-1130-forced-aligner` (ज़रूरी) | CC-BY-NC-4.0 | नहीं |
| वॉइस क्लोन XTTS-v2 (वैकल्पिक, सहमति माँगता है) | Coqui Public Model License | नहीं |
| लोकल अनुवाद `aya-expanse:8b` (वैकल्पिक) | CC-BY-NC-4.0 | नहीं |
| लोकल सुनना Qwen3-ASR-1.7B और Qwen3-ForcedAligner | Apache-2.0 | हाँ |
| ffmpeg (LGPL बिल्ड) | LGPL-2.1 | हाँ |

सेटअप पेज हर डाउनलोड के आगे उसका लाइसेंस दिखाता है।

## स्थिति

RTX 5080 वाले Windows 11 पर, और बिना ग्राफ़िक्स सपोर्ट वाले साफ़ इंस्टॉल से परखा गया: लिंक और फ़ाइलें,
जले हुए सबटाइटल और `.srt`, फ़्रेंच और अरबी, रोकना, फिर से शुरू करना, रद्द करना और दोबारा चलाना, जोड़ने
के तीनों तरीक़े (Claude और ChatGPT सदस्यताएँ, लोकल Ollama), चैट टूल, और ऊपर दी गई सुरक्षा जाँचें। अभी
नहीं परखा गया: macOS, Linux, GitHub Copilot और Antigravity सदस्यताएँ।

## लाइसेंस

tarjim हर किसी के लिए मुफ़्त है, कंपनियों के लिए भी: इसे किसी भी उद्देश्य से इस्तेमाल करें, पढ़ें-समझें,
बदलें और साझा करें। बस एक चीज़ की अनुमति नहीं है, और वह है **इसे बेचना**: कोई भी tarjim को नहीं बेच सकता,
और न ही ऐसा कोई उत्पाद या सेवा (होस्टिंग और सशुल्क सहायता समेत) बेच सकता है जिसका मूल्य tarjim से आता हो।
[LICENSE.md](LICENSE.md) (Apache License 2.0, Commons Clause के साथ) देखें; पूरा बाध्यकारी पाठ (अंग्रेज़ी)
यहाँ है: [../../LICENSE](../../LICENSE)।

tarjim जो मॉडल डाउनलोड करता है, उनके अपने लाइसेंस हैं, और उनमें से कुछ व्यावसायिक उपयोग की मनाही करते
हैं: काम के लिए इन मॉडलों का इस्तेमाल करने से पहले ऊपर दी गई मॉडल लाइसेंस की तालिका देखें।
